"An HTTP-based login attempt was captured against the phpMyAdmin interface hosted on the target (192.168.70.136), initiated from the attacking host (192.168.70.135). Traffic was isolated using the Wireshark display filter http.request.method=="POST", which restricts the packet list to HTTP form submissions. Following the corresponding TCP stream revealed the submitted username and password in plaintext within the POST request body. Although the specific credentials tested were rejected by the application ('incorrect password'), the capture confirms that the phpMyAdmin login form transmits authentication data over unencrypted HTTP rather than HTTPS. This means that any valid login attempt — successful or not — is exposed to interception by an attacker positioned on the same network segment, e.g. via ARP spoofing or a compromised switch. This finding reinforces the recommendation to enforce TLS/HTTPS on all administrative web interfaces."

Traffic was captured between the attacking host (192.168.70.135) and the target (192.168.70.136). The FTP session shows the username and password transmitted in cleartext, demonstrating that unencrypted protocols expose credentials to any party able to observe traffic on the network segment. This finding supports the recommendation to replace FTP with SFTP/FTPS across the network."
